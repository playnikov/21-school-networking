# Linux Monitoring

Пять bash-скриптов, которые постепенно превращаются в инструмент мониторинга системы: от простого вывода до исследования файловой системы с настраиваемым цветным оформлением.

## Содержимое

| Каталог | Что делает |
|---------|------------|
| `01/` | Первый вариант: `main.sh` вызывает `error.sh`, проверяет корректность ввода и завершает работу с кодом ошибки |
| `02/` | `info.sh` собирает сведения о системе (хост, часовой пояс, пользователь, ОС, uptime, IP, маска, шлюз, RAM, диск), `write.sh` пишет их в файл, `main.sh` связывает всё вместе |
| `03/` | Тот же сбор, но с цветным выводом: `color.sh` хранит коды цветов, `main.sh` проверяет аргументы |
| `04/` | Цвета выносятся в конфиг: `color.conf` (пользовательский) и `color_default.conf` (значения по умолчанию), разбор и валидация в `main.sh` |
| `05/` | Исследование файловой системы: `main.sh` проверяет аргумент и запускает `script05.sh`, который считает каталоги, файлы по типам, топ-5 каталогов и топ-10 файлов по размеру |
