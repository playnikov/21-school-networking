# Основы сетей. Часть 2

Вторая часть курса: статическая маршрутизация и прикладные протоколы — NTP, DNS, DHCP, SSH. Всё собрано в GNS3 на маршрутизаторах Cisco и VPCS-хостах.

## Содержимое

| Путь | Что это |
|------|---------|
| `static.pcap` | Дамп трафика при настройке статической маршрутизации между сетями |
| `ntp.pcap`, `ntp.txt` | NTP-обмен: порты, транспорт, метка времени |
| `dns.pcap`, `dns.txt` | DNS-запрос и ответ, разбор типа и класса записи |
| `dhcp.pcap`, `dhcp.txt` | Процесс получения адреса по DHCP |
| `ssh.pcap` | Сессия SSH: согласование алгоритмов и обмен данными |
| `Part1/` | Статическая маршрутизация, три маршрутизатора |
| `Part2/` | Настройка NTP-сервера и клиентов |
| `Part3/` | DNS на маршрутизаторе |
| `Part4/` | DHCP-сервер и клиентский ПК (VPCS) |
| `Part5/` | SSH-доступ к маршрутизатору |

В `project-files` — конфиги устройств (`startup-config.cfg`), дампы и логи GNS3.
