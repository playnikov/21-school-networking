# Linux Network

Настройка сети на виртуальных машинах Linux: адресация, маршрутизация, измерение пропускной способности, межсетевой экран, DHCP, NAT и SSH-туннели.

## Содержимое

| Путь | Что это |
|------|---------|
| `REPORT.md` | Полный отчёт по восьми частям задания со скриншотами команд |
| `images/` | Скриншоты выполнения (`screen1.png` … `screen115.png`) |
| `images/part5_network.png` | Схема сети из части про статическую маршрутизацию |

## Что разобрано в отчёте

1. `ipcalc` — расчёт адреса сети, перевод масок, границы хостов, localhost и служебные диапазоны.
2. Статическая маршрутизация между двумя машинами.
3. `iperf3` — измерение скорости канала.
4. Сетевой экран на `iptables`.
5. Статическая маршрутизация в сети из нескольких подсетей и маршрутизаторов.
6. Динамическая выдача адресов через DHCP (`isc-dhcp-server`).
7. NAT и проброс трафика наружу.
8. Дополнительно: SSH-туннели.
