# Основы сетей. Часть 3

Продвинутая настройка оборудования Cisco: VLAN, агрегирование каналов, динамическая маршрутизация и резервирование шлюза.

## Содержимое

| Путь | Что это |
|------|---------|
| `Part1/` | Виртуальные локальные сети (VLAN) на коммутаторах, VPCS-хосты в разных VLAN |
| `Part2/` | Расширение канала: агрегирование нескольких линков между коммутаторами, дампы по каждому физическому интерфейсу |
| `Part3/` | Динамическая маршрутизация между маршрутизаторами |
| `Part4/` | Резервирование: пара маршрутизаторов с общим виртуальным шлюзом |

В `project-files` — конфиги устройств, дампы перехвата и логи. В `Part1` и `Part2` лежат крупные бинарные файлы `c3745_*_rom`, `*_slot0`, `*_ssa` — это содержимое памяти виртуальных маршрутизаторов, которое GNS3 сохраняет вместе с проектом.
