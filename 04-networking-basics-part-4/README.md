# Основы сетей. Часть 4

Анализ трафика: разбор готовых дампов в Wireshark и tcpdump, поиск следов reverse shell, генерация собственных пакетов на Python.

## Содержимое

| Путь | Что это |
|------|---------|
| `answers.txt` | Ответы по разбору дампа: адреса источника и назначения reverse shell, протокол, переданные команды |
| `Task_1/task1.pcap` | Дамп для исследования сетевых пакетов |
| `Task_2/some_troubled_traffic.pcapng` | «Проблемный» трафик, в котором нужно найти сессию reverse shell |
| `Task_3/sent_message.pcapng` | Дамп с пакетом, отправленным скриптом |
| `main.py` | Скрипт на Scapy: собирает IPv4/TCP-пакет с текстовой нагрузкой и отправляет его на локальный порт |
| `report.docx` | Итоговый отчёт по трём заданиям |
