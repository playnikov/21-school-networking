# Основы Linux

Четыре задания по администрированию и защите Linux: сбор информации о системе, настройка пользователей и прав, мониторинг через почту, защита встроенными средствами.

## Содержимое

| Путь | Что это |
|------|---------|
| `task1/get_all_info.sh` | Скрипт сбора информации о дистрибутиве: пакеты, процессы, порты, сведения о железе и сети; результат пишет в файл `info` |
| `task1/OS_RESULT.tar` | Архив с выгрузкой системы (список пакетов, процессы, состояние диска и сети), собранный этим скриптом |
| `task2/setup_users.sh` | Скрипт создания группы и пользователей, настройки домашних каталогов, прав и записи в `sudoers` |
| `task3/main.cf` | Конфигурация Postfix для отправки почты через внешний SMTP-релей |
| `task3/cron.txt` | Задание cron для регулярной отправки отчёта |
| `task4/authorized_keys` | Публичный SSH-ключ, добавленный на сервер для входа без пароля |
| `task4/sshd_config` | Настроенный конфиг SSH-сервера: запрет парольного входа, ограничения доступа |
| `task4/iptables.txt` | Правила межсетевого экрана |
