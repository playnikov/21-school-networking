# Основы Windows

Базовая защита Windows: политики безопасности, шифрование диска BitLocker, аудит и правила брандмауэра. Скрипты снимают состояние системы, выгрузки приложены рядом.

## Содержимое

| Путь | Что это |
|------|---------|
| `task_1/get_sec_pol.ps1` | PowerShell-скрипт выгрузки политик безопасности в текстовый файл |
| `task_1/secpol.txt` | Выгрузка политик после настройки: требования к паролям, блокировка учётных записей, права пользователей |
| `task_2/crypt.txt` | Состояние шифрования тома через `manage-bde`: метод шифрования, статус защиты, тип ключа |
| `task_3/get_sec_pol.ps1` | Тот же скрипт выгрузки для второго этапа настройки |
| `task_3/secpol_2.txt` | Выгрузка политик после изменений — для сравнения с первой |
| `task_4/get_fw_rules.ps1` | Скрипт выгрузки правил брандмауэра Windows |
| `task_4/result.txt` | Выгрузка правил брандмауэра |
