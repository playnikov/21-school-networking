# Основы сетей. Часть 1

Первая часть курса по сетям: расчёт IP-адресов, знакомство с GNS3, разбор протоколов ARP и multicast, работа с моделью OSI/TCP-IP.

## Содержимое

| Путь | Что это |
|------|---------|
| `ip-1.txt` | Расчёт бинарной нотации адресов и разбиение сети на подсети под сегменты с разным числом хостов |
| `arp.pcap`, `arp.txt` | Дамп ARP-обмена и его расшифровка (MAC широковещательного запроса) |
| `multicast.pcap`, `multicast.txt` | Дамп multicast-трафика и MAC-адрес группы |
| `Part2/` | GNS3-проект: два маршрутизатора, стартовые конфиги |
| `Part3/` | GNS3-проект с дампами ICMP-обмена между R1 и R2 |
| `Part4/` | GNS3-проект с дампами ICMP-обмена между R1 и R2 |

Каталоги `project-files` внутри частей созданы GNS3: там лежат конфиги устройств, дампы и логи запуска.
