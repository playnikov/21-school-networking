# Basic CI/CD

Пайплайн CI/CD для собственных утилит `cat` и `grep`: сборка, проверка стиля, интеграционные тесты, деплой на удалённую машину и уведомления.

## Содержимое

| Путь | Что это |
|------|---------|
| `cat/` | Утилита `s21_cat` на C: `cat.c`, `cat.h`, `main.c`, `Makefile`, тесты в `tests_cat/` |
| `grep/` | Утилита `s21_grep` на C: `grep_parser.c`, `grep_print.c`, `main.c`, `Makefile`, тесты в `tests_grep/` |
| `test-job.sh` | Стадия тестов: собирает обе утилиты, прогоняет тесты и падает, если есть `FAIL`, `FAIL_FUNC` или `FAIL_VALGRIND` |
| `deploy.sh` | Стадия деплоя: копирует бинарники на удалённый хост через `scp` и раскладывает их в `/usr/local/bin` |
| `notify.sh` | Необязательная стадия уведомлений: отправляет в мессенджер статус и ссылку на пайплайн |
| `REPORT.md` | Отчёт по всем стадиям со скриншотами и фрагментами логов |
| `images/` | Скриншоты работы пайплайна |
| `cat/tests_cat/files/`, `grep/tests_grep/files/` | Тестовые данные для проверки граничных случаев, включая крупные файлы |
